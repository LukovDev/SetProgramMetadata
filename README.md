# Set Program Metadata

Полезный набор инструментов, для редактирования метаданных программ в Windows.</br>

Краткая инструкция:</br>

### Содержимое:
- `build/` - Папка сборки и инструментов.
  - `out/` - Временная папка, которая создаётся для хранения ресурсов во время работы скрипта.
  - `tools/` - Папка с инструментами, необходимыми для создания и редактирования метаданных программы.
  - `config.json` - Файл конфигурации метаданных программы.
- `src/` - Содержит сам скрипт.
- `apply_all.bat` - Записать всё (метаданные и иконку).
- `delete_all.bat` - Удалить всё (иконку и метаданные).
- `delete_icon.bat` - Удалить только иконку (метаданные оставить).
- `delete_info.bat` - Удалить только метаданные (иконку оставить).

### Файл конфигурации:

Выглядит примерно так:
```json
{
    "icon-path":          "icon.ico",
    "company-name":       "My Company",
    "description":        "My Awesome App",
    "file-type":          1,
    "file-version":       [0, 0, 0, 0],
    "product-name":       "My Project",
    "product-version":    [0, 0, 0, 0],
    "legal-copyright":    "2025 My Company",
    "legal-trademarks":   "My Trademark",
    "file-original-name": "myapp.exe",
    "file-internal-name": "myapp",
    "path-to-file":       "app.exe"
}
```

Думаю тут и так всё понятно и пояснять не надо. Просто измените поля под себя и заполните пустые поля при необходимости.</br>

Единственное НО:</br>
Поле `"file-type"` обозначает разный тип программы:</br>
1 - `.exe`</br>
2 - `.dll`</br>
3 - `.sys, и тд.`</br>
4 - `Font file.`</br>

Также вы можете сделать поле `"icon-path"` равным `null`. Тогда иконка не будет меняться/добавляться.</br>
Но это касается не только поля иконки. Вы можете применить `null` к любому полю, если не хотите его менять/добавлять (кроме `"path-to-file"`, иначе скрипт не найдет программу).</br>

### Как использовать?

1. Настройте файл конфигурации `build/config.json`. Обязательно укажите, чтобы `"path-to-file"` имел значение пути до вашей программы. Например: `"My Program.exe"` или `"../bin/MyGame.exe"`</br>
2. Положите вашу программу в корень этой утилиты (в корневую директорию, где лежат папки `build`, `src`, и другие файлы.</br>
3. Чтобы убрать иконку, запустите скрипт `delete_icon.bat`.</br>
4. Чтобы убрать метаданные, запустите скрипт `delete_info.bat`.</br>
5. Чтобы убрать и иконку, и метаданные, запустите скрипт `delete_all.bat`.</br>
6. Чтобы применить вашу конфигурацию (из файла `config.json`), запустите скрипт `apply_all.bat`.</br>
